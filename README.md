# Artur Rodrigues — academic website

Personal academic website built with [Quarto](https://quarto.org/) and published through GitHub Pages.

## Preview locally

```bash
quarto preview
```

## Publish

Push to the `main` branch. The GitHub Actions workflow renders the site and deploys the generated `_site` artifact to GitHub Pages.

## Publication author names

Author names and order were checked against publisher-deposited Crossref DOI metadata on 8 October 2026. The verified records are saved in [data/publication-authors.json](data/publication-authors.json). When updating the publication list, use the DOI record rather than expanding initials from memory; some authors use different name forms across publications.
